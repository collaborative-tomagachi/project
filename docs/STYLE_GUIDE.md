# Style Guide

## Branch format

`[type]/P-[issue-no]-[title]`

### Branch Types

- spike
- feature
- bug
- release
- hotfix

### Issues

Issue number should reference the ticket ID associated to the work.

[Issue tracker](https://www.notion.so/Pet-Project-Board-3162c59fdd4480bf8badd2ae072b4779)

## Commit format

Commits should have the issue number at the top of the commit message i.e.

> P-[issue-no] fixing type issue
